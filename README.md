# CareerPilot AI — AI Career Companion Pro

A polished, responsive career command center designed for job seekers and professionals.

## Functional features
- Career readiness score and progress tracking
- Daily career action plan
- Resume AI improvement modal
- Interview Coach practice modal
- AI-ranked job matching
- Live job search/filtering
- Save/unsave jobs
- AI career insight panel
- Weekly momentum tracking
- Responsive desktop/tablet/mobile UX
- No API keys required for the demo

## Deploy to Vercel
Import this repository into Vercel. It is a standard Next.js app and requires no environment variables.

## Local development
```bash
npm install
npm run dev
```

## Production integrations
For a production version, connect an AI provider for resume/interview generation, authentication, a jobs API, database persistence and analytics. The current UI is deliberately functional without those services so it can be deployed immediately.
